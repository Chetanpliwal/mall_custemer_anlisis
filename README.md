# Customer Segmentation Project

### Project Overview
An unsupervised machine learning project designed to segment customers based on behavioral traits and demographic data (Annual Income and Spending Score) using K-Means clustering to uncover actionable target audiences.

### Key Features & Functionality
* **Machine Learning Clustering:** Implemented K-Means algorithm using `scikit-learn` to segment customers into distinct behavioral groups.
* **Purchase Pattern Analysis:** Evaluated customer income brackets alongside spending habits to find core market segments.
* **Interactive Visualizations:** Mapped clusters using scatter plots and comparative metrics inside Power BI.

### Tools & Technologies Used
* **Programming Language:** Python (`Pandas`, `Scikit-Learn`, `Matplotlib`, `Seaborn`)
* **Dashboarding Tool:** Microsoft Power BI
* **Dataset:** Mall Customer Segmentation Data (Kaggle)
